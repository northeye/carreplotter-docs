# carreplotter.northeye.org

Website of the CarReplotter app (GitHub Pages): the top page, the user guide, support contact and privacy policy.

| Page | English | Japanese |
| --- | --- | --- |
| Top / support | `index.html` | `ja/index.html` |
| User guide | `manual/*.html` | `ja/manual/*.html` |
| Privacy policy | `privacy.html` | `ja/privacy.html` |

The top page and the user guide are generated by `python3 src/build.py` and the generated HTML is committed
(GitHub Pages serves the files as they are; `.nojekyll`). Their texts are in the submodule `translations/`
([carreplotter-i18n](https://github.com/northeye/carreplotter-i18n), `site/<language>.json`); the structure of the user guide
(pages, headings, screenshots and the positions of the numbered marks) is in `src/manual.py`.
A page is generated for every language in `translations/site/`; untranslated texts fall back to English.

To change a text: edit `site/en.json` and `site/ja.json` in carreplotter-i18n and push to main. The workflow there
(`.github/workflows/site.yml`) asks this repository to rebuild: `.github/workflows/translations.yml` updates the submodule,
runs `src/build.py` and commits the result (the push publishes it to Pages). Pull before working here, since the workflow commits to main.
To do it by hand: `git submodule update --remote translations`, `python3 src/build.py`, and commit the result together with the submodule.

The privacy policy is written by hand in English and Japanese (it is a legal document and is not translated in carreplotter-i18n).
When you change it, update "Last updated" in both languages. `CNAME` sets the custom domain.
